# Color Hunter

**Система комп’ютерного зору для пошуку об’єктів заданих кольорів**

Програма для комп'ютеру, що дозволяє шукати об'єкти заданих кольорів на будь-яких зображеннях, визначати координати, центри, а також їхні контури

---

## Про проєкт

**Color Hunter** — це десктопна програма на Python, що використовує бібліотеку OpenCV для автоматичного виявлення, підрахунку та локалізації об'єктів на зображеннях за їхнім кольором.

Програма виконує:
*   Аналіз колірного простору в реальному часі.
*   Точне визначення координат об'єктів.
*   Автоматичну генерацію звітів та візуалізацію результатів.

Вся обробка виконується локально, з можливістю пакетної обробки цілих директорій з фото.

---

## Архітектура

### Графічний інтерфейс (PyQt6)
*   Вибір режиму: поодиноке фото або обробка теки.
*   Зручна панель вибору кольорів (понад 20 пресетів).
*   Керування збереженням результатів та відображенням масок.
*   Збереження налаштувань користувача між сесіями.

### Модуль аналізу (OpenCV)
*   Конвертація зображення: **BGR → HSV**.
*   Маскування за пороговими значеннями кольору.
*   **Морфологічна фільтрація:** видалення шумів та артефактів (Morphological Open/Close).
*   Алгоритм пошуку контурів та обчислення моментів зображення для пошуку центру об'єктів.

**Потік даних:**
Зображення → Препроцесинг (HSV) → Накладання маски → Фільтрація шуму → Детекція контурів → Логування та Візуалізація.

---

## Технологічний стек

*   **Мова програмування:** Python 3.10+
*   **Комп'ютерний зір:** OpenCV
*   **Графічний інтерфейс:** PyQt6
*   **Обробка даних:** NumPy
*   **Збереження даних:** output.jpg (для 1 фото), output тека (для цілого набору фото), TXT (для логів)

---

## Основні можливості

*   **Автоматична детекція:** Пошук об'єктів без ручного виділення областей.
*   **Підтримка відтінків:** Вміння працювати зі складними кольорами та різним освітленням.
*   **Координатний вивід:** Визначення точного центру (X, Y) кожного об'єкта.
*   **Пакетна обробка:** Обробка сотень зображень в автоматичному режимі.
*   **Логування:** Детальний запис результатів у `log.txt` з часовими мітками.
*   **Візуалізація:** Обведення контурами, прямокутниками та підпис координат безпосередньо на зображенні.

---

## Вихідні дані

Після запуску програми ви отримаєте:
1.  **Консольний вивід:** Кількість знайдених об'єктів.
    ```text
    Detected objects: 7
    ```
2.  **Зображення:** згенерується файл або тека файлів з обведеними контурами об'єктів та вказаними координатами кожного центру.
3.  **Лог-файл:** файл `log.txt` із детальною історією обробки та координатами кожного знайденого об'єкта.

## Початок роботи

### Системні вимоги
Переконайтеся, що у вас встановлені:
*   **Python 3.10+**
*   **Бібліотеки:** OpenCV, NumPy, PyQt6

---

### Встановлення

1. Клонуйте репозиторій:
```bash
git clone https://github.com/nikitosruban007/Color-Hunter-VisionX/
cd Color-Hunter-VisionX
```
2. Встановіть необхідні бібліотеки:
```bash
pip install opencv-python numpy PyQt6
```
3. Запустіть додаток:
```bash
python main.py
```

## Використання
1. Оберіть режим: "Обробка 1 фото" або "Обробка теки фото"
2. Натисніть "Обрати файл/теку" для вказання шляху до зображень
3. У сітці кольорів відмітьте потрібні пресети (наприклад, red, blue, lime)
4. Налаштуйте параметри відображення (показувати маски або результати)
5. Натисніть "Запустити"
